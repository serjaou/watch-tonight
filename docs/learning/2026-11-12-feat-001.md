## Concepts Covered
- How `pyproject.toml` consolidates package metadata, dev dependencies, task runner (`poethepoet`), linter/formatter (`ruff`), strict static type checking (`pyright`), architectural boundary enforcement (`import-linter`), and `pytest` configuration into a single file.

## C# / .NET Contrast
- In .NET, Clean Architecture boundaries are enforced by the compiler via separate `.csproj` files (`Domain.csproj`, `Application.csproj`, `Infrastructure.csproj`).
- In a single-package Python repo, any module can `import` any other module at runtime unless an explicit static tool like `import-linter` checks the import graph.
